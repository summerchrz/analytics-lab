# PowerPoint Patterns

Reusable VBA and slide-show automation patterns extracted from real decks,
generalized for learning and reuse.

Each folder is self-contained with a README and source module(s).

## Patterns

| Pattern | What it demonstrates |
|---|---|
| [`slide-show-countdown-timer`](slide-show-countdown-timer) | Windows `SetTimer` callback countdown during slide show; duration vs. end-time modes; named-shape text updates |
