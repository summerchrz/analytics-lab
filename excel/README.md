# Excel Patterns

Reusable VBA and workbook automation patterns extracted from real allocation /
planning workbooks, generalized for learning and reuse.

Each folder is self-contained with README, module source, and named-range
configuration notes.

## Patterns

| Pattern | What it demonstrates |
|---|---|
| [`monthly-tab-allocation-workbook`](monthly-tab-allocation-workbook) | Month-tab regex filtering, zero-column hide, CSV export, dedup rollup, Tableau bridge formulas, adds-by-month pivot |
