# Projects

This folder is for larger, end-to-end builds that span multiple files, tools, or milestones.

Use it for projects that are too substantial to be a single reusable pattern and too implementation-heavy to live only as a case study.

## Planned structure

Each project should normally have its own folder and README.

Example:

```
projects/
└── eight-week-automation-project/
    ├── README.md
    ├── data/
    ├── src/
    ├── tests/
    ├── notebooks/
    └── docs/
```

See [PROJECT_GUIDE.md](../PROJECT_GUIDE.md) for the recommended workflow and public-safety checklist.
