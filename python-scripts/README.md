# Python Scripts

Data validation, automation, and analysis scripts built for learning and
portfolio purposes, using public or synthetic data only.

## Projects

### [`meeting-caption-sidecar`](meeting-caption-sidecar)

Personal Windows tool: saves live accessibility captions (text on screen) to a
local log, Pulse catch-up during calls, debrief after hang-up. No audio
recording.

- **Full guide:** [meeting-caption-sidecar/README.md](meeting-caption-sidecar/README.md)
- **Quick checklist:** [meeting-caption-sidecar/SETUP.md](meeting-caption-sidecar/SETUP.md)

### [`messy-bi-export-to-tidy-table`](messy-bi-export-to-tidy-table)

Pandas pipeline for turning messy BI Excel exports into tidy tables.

### [`openpyxl-chart-face-strip`](openpyxl-chart-face-strip)

Data-only Excel chart strip writes (don’t recreate charts); locked published
seed when the live feed can’t reproduce history.
